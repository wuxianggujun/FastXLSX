# FastXLSX API Design Docs

先标记 Streaming write/Streaming read/Patch/In-memory 与 public facade，再定义输入、所有权、状态、失败、保存、内存和 OpenXML side effects。

Public Doxygen 必须写清：
- 顺序/随机访问与生命周期。
- `has_pending_changes()` 和 `has_unsaved_changes()` 的区别。
- Save Doxygen 必须区分 internal stage、package write 与 public state commit，并说明失败时 dirty/pending/unsaved/last-error 不变量。
- In-memory strict/lossy projection，默认 strict，lossy 显式 opt-in。
- Structured diagnostics 只暴露稳定 category/context，不泄漏 XML、parser 或 package internal 状态；typed exception 保持 `FastXlsxError` catch compatibility。
- preserve/audit/fail/edit 和 non-goals。
- Hyperlink 必须区分 internal worksheet-local XML 与 external `.rels` relationship mutation；写清 duplicate/range、XML escaping、cell/style、formula/definedName 和 linked-object side effects，不能把 internal hyperlink 扩大为完整 hyperlink 编辑。
- Data validation 必须写清 shared owning rule、single-/multi-range `sqref`、formula1/formula2 shape、prompt/error escaping、container/count/schema-order guardrail，以及不创建关系、不求值/请求重算的边界。还必须说明 materialized row/column insert/delete 会从 current effective strict projection 对 `sqref` 做 shift/expand/clip/full removal，保留 single-cell result、删除 empty rule/container，但 point edit、copy/move 与 linked objects 不同步；不能扩大为完整 validation 对象模型。
- Patch conditional-format add 必须写清三个 public API 与 overload 边界、writer-compatible new-rule ownership、独立 source structural/priority audit、effective priority `max + 1`、planned rename/added worksheet、`conditional_format_count` 诊断和 failure-before-state-change/retry。Doxygen 必须声明只追加 worksheet-local `<conditionalFormatting>`，不改 cells、relationships、content types、styles/dxf、calc metadata 或 linked objects；advanced/custom/dxf/formula/cellIs/multiple-rule source payload 原样保留且不投影/接管，结构或 priority 异常 fail，并明确窄 add 不等于完整 existing-workbook conditional-formatting object model。
- Patch conditional-format update 必须写清四种 rule 的 single/`span`/initializer-list overload、current-effective reader index、source/same-session object、原 priority/source-order 保留、ranges + kind/payload replacement、planned rename/added worksheet、`conditional_format_update_count` 与 failure/save retry。Doxygen 必须声明 strict source projection、advanced/custom/dxf/formula/cellIs/multiple-rule fail、只改 worksheet-local XML、package side-effect preservation、structural non-sync，并明确窄 update 不等于任意 source takeover 或完整 object model。
- Auto-filter 必须区分 worksheet-root element 与 table-local filter part；写清 whole-element set/clear、旧 criteria/sort metadata 丢弃、clear absent no-op、single range、existing ref/duplicate/schema guardrail、optional-range diagnostic，以及不创建关系/content type/calc metadata。Materialized row/column insert/delete 会 bounded translate root range：insert shift/expand，delete shift/clip/full removal，single-cell final range 保留；surviving changed filter 含 criteria/sort child 时 fail，完整删除可移除 whole element。Copy/move 与其他 linked-object mutation 不联动；不能扩大为完整 filter 对象模型。
- Merged-cell 必须写清 multi-cell `CellRange`、merge duplicate/overlap fail、unmerge exact-only、partial overlap fail、absent disjoint no-op，以及 container/count/direct-child/ref/schema guardrail；同时声明 metadata-only、保留非左上角 cell record/value/style/formula、relationships、content types、tables、`calcPr`/`calcChain`。显式 merge/unmerge 后的 range 会随 `WorksheetEditor` row/column insert/delete bounded translate，但 copy/move 与其他 linked-object mutation 不联动；不能扩大为完整 merged-cell 对象模型。
- Freeze-pane 必须写清 primary `workbookViewId="0"` direct pane ownership、row/column frozen count、`(0,0)` clear、单轴 active pane、topLeftCell 上界、missing/self-closing view expansion，以及 split/frozenSplit/pivotSelection/失效 selection fail；同时声明保留其他 view、合法 selection、cells、relationships、content types、tables 与 calc metadata，不能扩大为完整 worksheet view 对象模型。
- Streaming classic-note writer 必须写清 new-workbook-only、one-based single-cell coordinate、owning non-empty simple author/text、duplicate-cell rejection、unwritten target 不创建 cell、state 随 note count/copied bytes 增长，以及 `close()` 生成 author table/comments/hidden VML/relationships/content types 并在成功后释放构建状态、失败保留 retry。Rich/threaded comments、visibility/shape customization、VML payload API 与 existing-workbook edit 必须明确排除。
- Patch classic-note 必须写清 existing-workbook 模式、one-based single-cell、owning non-empty simple author/text、duplicate/missing/no-op 语义、missing target 不创建 cell、same-session generated-part regeneration，以及 worksheet XML/`.rels`/comments/VML/content-types/manifest/public diagnostics 的事务边界。Add 默认拒绝 source-owned classic/threaded comments 与任何 VML relationship；update/remove 仅接管 bounded projection 和 comments/VML serializers exact 匹配、且 URI/part-name 归一化后没有其他 worksheet、part 或 package-root 入边的 writer-canonical source pair，入边审计必须识别 percent-encoded path 与 query/fragment alias。最后一条删除清理 `<legacyDrawing>`、relationships、parts 与不再使用的 content types。Rich/threaded comments、unknown/Excel-rewritten VML、shape customization、persons、cell/formula sync 和通用 VML 编辑必须明确排除。
- Patch table lifecycle 必须写清 `add_table()` / `update_table()` / `remove_table()` 复用 Streaming/Patch shared owning `TableOptions`、validator 与 serializer，并把 worksheet `<tableParts>`、owner `.rels`、table parts、content types、manifest/EditPlan、public diagnostics 与 pending/watermark 作为事务。Doxygen 必须声明 source/planned-rename/same-session-added worksheet 与 lifecycle overlay、workbook-wide ASCII-insensitive name、id/part uniqueness、same-sheet range non-overlap，以及 source table 的 bounded projection、无 child relationships 与 normalized exclusive inbound ownership。Update 保留 id/relationship/part/order 且 identical clean no-op；remove 关闭完整 graph，最后一项删除 container，name/range 可复用但 id/part 本 session 不复用。还必须明确不读取或修改 header/data/totals cell payload、不求值、不生成 cached result、不随 structural mutation 同步，并区分窄 metadata lifecycle 与完整 table object model；失败在发布前不得污染 package/public state 且可 retry。
- Bounded worksheet reader 必须写清 forward-only row/cell source order、每个 borrowed field 的 callback lifetime、formula/cached split、sharedStrings/style 是 opaque index 还是 resolved value、table-count validation 边界、XML window/active-cell text 上限、stored/DEFLATE entry ownership与 callback exception retry；声明 read-only、no seek/DOM/dense matrix/CellStore/Patch handoff，并对 rich/formula metadata 等 unsupported projection 明确 fail。
- Bounded simple sharedStrings companion 必须与 worksheet index projection 显式分离，写清 zero-based source order、borrowed text lifetime、simple/empty/entity decode、root count validation 边界、XML window/active-item text 上限、unique internal relationship + normalized target + content-type audit、stored/DEFLATE ownership与 callback retry；rich/phonetic/extension/extra metadata 默认 fail，禁止完整 table、自动 worksheet index resolution 或 Patch/In-memory handoff。
- Bounded rich sharedStrings run companion 必须独立于 strict simple projection，写清 item start/run/end order、失败前 partial callbacks、run text borrowed lifetime、simple 单 run compatibility、zero-based item/run index、owning bold/italic/direct-ARGB、XML window/item/run/runs/nesting guardrail 与 OPC audit。Fixed default font metadata 可 accept；mixed shape、phonetic/extension、其他 font/theme/tint/property 明确 fail。禁止完整 table、format inheritance、自动 worksheet index resolution 或 Patch/In-memory handoff。
- Bounded cell-formats companion 必须与 worksheet style index 显式分离，写清 custom format-code borrowed lifetime、zero-based cellXfs、opaque number-format/font/fill references、apply/alignment owning values、container count 与 duplicate-id 边界、XML window/format-code/nesting/custom-id count guardrail、unique internal styles relationship + normalized target + content-type audit、stored/DEFLATE ownership与 callback retry；border/base-style/protection/extension 和其他 xf/alignment metadata 必须明确 accept-no-op 或 fail，禁止完整 registry、自动 worksheet index resolution 或 Patch/In-memory handoff。
- Bounded style-components companion 必须独立遍历并写清 zero-based font/fill index、owning bold/italic/direct-ARGB 与 fill-pattern values、container count、XML window/nesting/component-count guardrail、styles relationship/target/content-type audit 和 callback retry。只无损投影当前 writer-compatible subset；non-default font/theme、其他 color/pattern/gradient 明确 fail，禁止完整 registry、自动 cellXfs/worksheet-index resolution、theme inheritance 或 existing-style rewrite。
- Bounded worksheet metadata companion 必须独立于 row/cell read 与 Patch mutation，写清 primary frozen pane、worksheet-root auto-filter、zero-based merged range 的 source order、owning lifetime 和 partial-callback completion signal；XML window/nesting/reference/view/retained-merge guardrail、schema/QName/count/overlap/unsupported pane fail 必须显式。其他 view 只审计、table-local filter 不读取、OPC state 无副作用，禁止 DOM/dense matrix/CellStore 或 Patch/In-memory handoff。
- Bounded worksheet data-validation companion 必须独立于通用 metadata read 与 Patch mutation，写清 zero-based source order、owning `vector<CellRange> + DataValidationRule`、partial-callback completion signal、entity decode 和 writer-compatible formula shape。XML window/nesting/validation/range count、`sqref`、formula 与 prompt/error text 必须有 guardrail；container count/direct child/QName/schema、boolean/enum、foreign target-child 与 prompt-window metadata 必须明确 accept 或 fail。禁止公式求值、cell-value validation、overlap repair、OPC side effect、DOM/CellStore 或 Patch/In-memory handoff。
- Patch data-validation remove 必须写清 index 是当前 effective worksheet 的 zero-based source order，并与 reader view index 对齐；same-session add/remove 会改变后续 index。删除前必须完成 strict bounded projection，final child 删除 container，其他删除归一化 count；planned rename/added worksheet、failure-before-commit/retry、无 relationship/content-type/calc side effect 都是 public contract。后续 materialized row/column insert/delete 会 strict translate effective `sqref`，只改 changed opening tag/必要 count，保留 rule/formula/prompt/error；point edit、copy/move 与 linked objects 仍不做 range sync。
- Bounded worksheet hyperlink companion 必须独立于 row/cell/metadata read 与 Patch mutation，写清 zero-based source order、owning `CellRange`/kind/location/external-target/display/tooltip、partial-callback completion signal，以及 relationship id 保持 package-local。Internal `location` 不要求 `.rels`；external target 必须通过 owner-local worksheet relationship 解析并审计标准 type、`TargetMode="External"` 与非空 target。XML window/nesting/ref/id/target/metadata-text 必须有 guardrail；唯一 container/direct child/QName/namespace scope/schema、恰好一个 location/id、unsupported metadata、duplicate/range overlap 必须明确 fail。禁止 target reachability、relationship create/repair/prune、content-type/manifest/cell/style side effect、DOM/CellStore 或 Patch/In-memory handoff。
- Bounded worksheet conditional-formatting companion 必须是独立 public traversal，不与 row/cell/metadata read 或 Patch mutation 隐式 handoff；写清 zero-based source order、owning multi-range `sqref`、priority、writer-compatible color-scale/data-bar/3Arrows payload、partial-callback completion signal 和 callback retry。XML window/nesting/format/range count 与 `sqref` 必须有 guardrail；唯一 container/direct child/QName/namespace scope/schema、单个 direct `cfRule`、priority、`cfvo`/color/icon threshold shape 与 ARGB 必须明确 fail/accept。Advanced/custom icon sets、advanced data bars、`dxf`/styles、formula/cellIs、multiple-rule container 和 unsupported metadata 必须 fail；禁止公式求值、style repair、OPC side effect、DOM/CellStore 或 Patch/In-memory implicit handoff。Patch add 使用独立 structural/priority audit，不复用或放宽 reader projection。
- Bounded worksheet table companion 必须独立于 row/cell/metadata read，写清 `<tableParts>` zero-based source order、owning table id/range/name/displayName/basic columns、writer-compatible totals function/label、table-local auto-filter 与 style flags、partial-callback completion signal 和 callback retry。Relationship id/part path 保持 internal；tableParts count/direct child/QName/relationship namespace/schema、标准 internal table relationship、percent-decoded normalized unique target、part presence/content type 与 table root/header/totals/filter/style boundary 必须审计。XML window/nesting/table/id/target/name/column/range 必须有 guardrail；visible totals row 必须至少有一个 totals function，且 table-local filter boundary 必须排除最后一行。Calculated/other totals formula、完整 filter/sort、extension 与 unsupported table semantics 必须 fail。禁止 header/data/totals cell-payload inference、reader 自身的 workbook-wide name uniqueness claim、relationship/content-type/manifest mutation、table DOM/CellStore 或 In-memory handoff；Patch 只能显式复用成功的 bounded writer-compatible projection 做 source audit。
- Bounded worksheet image companion 必须独立于 row/cell/metadata/table read 与 Patch mutation，写清 drawing zero-based source order、owning `editAs`/from-to marker/EMU offset/transform extent/name/description/format/encoded size、partial-callback completion signal 和 callback retry。Worksheet/drawing relationship id 与 part path 保持 internal；唯一 direct standard drawing reference、writer-compatible direct `xdr:twoCellAnchor`/picture、drawing-local standard internal image relationship、percent-decoded normalized target、part presence/content type、PNG/JPEG signature 与 ZIP size/CRC 必须审计。XML window/nesting/image/id/target/name/description/numeric/media 必须有 guardrail；unique media 每次调用只 drain 一次但不保留/暴露 bytes、不 decode pixels。`xdr:oneCellAnchor` / `xdr:absoluteAnchor` 元素、chart/shape/group/connector、crop/rotation/position transform、picture hyperlink 与 unsupported drawing semantics 必须 fail。禁止 OPC mutation、完整 drawing DOM/object model、CellStore 或 Patch/In-memory handoff；no-images build 保留 symbol 但调用抛错。
- Bounded worksheet comments companion 必须独立于 row/cell/metadata/image read 与 Patch mutation，写清 comments-part zero-based source order、owning one-based row/column、resolved author/simple text、partial-callback completion signal 和 callback retry。唯一 standard internal comments relationship、percent-decoded normalized target、part presence/content type 必须审计；author table、comment/author count、单 author/aggregate author/comment text、cell ref、authorId、shapeId、relationship id/target 与 XML window/nesting 必须有 guardrail。Single-cell uppercase A1、authorId bounds、duplicate ref 与 optional numeric shapeId 必须审计。Optional direct `legacyDrawing` 只审计 owner-local standard internal VML relationship、target、part/content type 与 ZIP-entry presence，不解析 payload/visibility/shape。Rich/phonetic/extension、worksheet-local threaded-comment relationship 与 unsupported metadata 必须 fail；persons part 不跟随、不投影。禁止 OPC mutation、完整 comments DOM、row/cell attachment、CellStore 或 Patch/In-memory handoff。

禁止把 internal 类型、preservation evidence、公式文本、窄图片或窄 classic-comment 能力扩大为 public/full support。
